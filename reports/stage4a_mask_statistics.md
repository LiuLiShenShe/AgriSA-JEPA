# Stage 4A — Mask 统计与几何公平性报告

> 数据：`agrifield40k-v1_train.csv`（PROVISIONAL）。样本：**60 张**真实农业图像，按来源分层并覆盖高中低植被密度。
> 复现命令：
> ```
> ./.venv/bin/python -m tools.visualize_agri_masks \
>     --manifest data/frozen/agrifield40k-v1_train.csv \
>     --root /data/datasets/AgriField-40K \
>     --num-images 60 --device cpu --out-dir runs/stage4a_masks
> ```
> 机器可读结果：`runs/stage4a_masks/mask_statistics.json`

## 1. 本报告要回答的问题

在正式训练之前，必须先回答三个问题（协议 §6.2 / §7）：

1. **引导是否真的改变了目标块的位置分布？** 如果没有改变，任何下游差异都不能归因于方法。
2. **几何是否仍然公平？** 目标块面积、每块 patch 数、上下文/目标排斥关系是否与官方随机掩码一致？
3. **C3 对照是否有效？** 打乱后的先验是否保留数值分布、但失去空间对齐？

## 2. 方法设置

| 方法 | 先验 | 引导强度 |
|---|---|---|
| B | 无（官方随机多块） | — |
| C1 | ExG 植被显著图 | λ=6.0, K=16 |
| C2 | 亮度 Sobel + ExG 梯度组合（w=0.5） | λ=6.0, K=16 |
| C3 | C2 先验的 16×16 单元逐图置换 | λ=6.0, K=16 |

对同一张图，四种方法使用**完全相同的目标块尺寸、长宽比、块数量**，因此差异只来自"放在哪里"。

## 3. 结果

### 3.1 目标块内的结构覆盖率（核心判据）

| 方法 | 目标块内平均植被分数 | 相对 B 的配对差 | 胜/负（n=60） | 符号检验 p |
|---|---:|---:|---:|---:|
| B | 0.4274 ± 0.112 | — | — | — |
| **C1** | **0.5008 ± 0.116** | **+0.0734** | **53 / 7** | **2.9 × 10⁻⁹** |
| C2 | 0.4274 ± 0.120 | +0.0001 | 26 / 34 | 0.30 |
| C3 | 0.4174 ± 0.137 | −0.0099 | 24 / 36 | 0.12 |

| 方法 | 目标块内平均边界分数 | 相对 B 的配对差 | 胜/负（n=60） | 符号检验 p |
|---|---:|---:|---:|---:|
| B | 0.2777 ± 0.041 | — | — | — |
| C1 | 0.2778 ± 0.045 | +0.0001 | 33 / 27 | 0.44 |
| **C2** | **0.2940 ± 0.037** | **+0.0162** | **53 / 7** | **2.9 × 10⁻⁹** |
| C3 | 0.2780 ± 0.041 | +0.0003 | 27 / 33 | 0.44 |

**结论：**

- **C1 确实把目标块移到了更多植被上**（+7.3 个百分点，53/60 张图改善，p ≈ 3×10⁻⁹）。
- **C1 没有把目标块移向边界**（+0.0001，p=0.44）——说明 C1 与 C2 捕捉的是不同的结构信息，不是同一个信号的两个版本。
- **C2 确实把目标块移到了更多边界上**（+1.6 个百分点，53/60，p ≈ 3×10⁻⁹），且**没有改变植被含量**（p=0.30）。
- **C3 两项都没有改善**（边界 +0.0003，p=0.44；植被 −0.0099，p=0.12）。

这构成一个干净的三重分离：

```
C1: 植被 ↑↑ , 边界 =      （植被引导有效）
C2: 植被 =  , 边界 ↑↑      （边界引导有效）
C3: 植被 =  , 边界 =       （数值分布相同但空间错位 → 无效）
```

C3 的结果是本轮最重要的对照证据：它保留了 C2 先验的**数值分布**与**相同的 λ、K**，只破坏了与图像的空间对应关系，结果引导收益消失。这支持"**先验必须与图像空间对齐才有用**"，而不是"任何有偏采样都能带来同样的变化"。

### 3.2 几何公平性

| 指标 | B | C1 | C2 | C3 |
|---|---:|---:|---:|---:|
| 目标块总面积（patch） | 176.3 ± 15.2 | 176.3 ± 15.2 | 176.3 ± 15.2 | 176.3 ± 15.2 |
| 每个目标块 patch 数 | 44.08 | 44.08 | 44.08 | 44.08 |
| 目标 patch 数（去重） | 115.8 | 93.3 | 101.6 | 104.6 |
| 上下文可见 cells | 109.2 | 131.7 | 123.4 | 120.4 |
| 上下文/目标重叠 | 0 | 0 | 0 | 0 |
| 覆盖率（目标∪上下文） | 0.8789 | 0.8789 | 0.8789 | 0.8789 |
| 重复目标面积 | 60.5 | 83.0 | 74.7 | 71.7 |

**保持不变的量**：目标块总面积、每块 patch 数、块数量、覆盖率、上下文—目标排斥（严格为 0）。

**发生变化且必须如实报告的量**：目标块**去重后**覆盖的 patch 数下降（B 115.8 → C1 93.3），因为引导后的目标块更集中、彼此重叠更多（重复面积 60.5 → 83.0）。相应地，上下文可见 cells 增加（109.2 → 131.7）。

这意味着：C1/C2/C3 与 B 的差异**不是**由目标块变大或总掩码面积变化造成的（这些完全一致），但**上下文可见面积确实略大**。这是一个真实的、由"目标块更集中"带来的附带几何差异，无法通过候选机制消除，因为目标块面积固定且允许块间重叠。它属于官方规则允许的行为（官方随机掩码同样允许目标块重叠），但**在解释下游差异时必须记住**：C1 的上下文信息量略多于 B。

> 这一条在最终报告的"结构引导提升是否可能仅由采样几何或计算成本差异导致？"一问中被明确引用。

### 3.3 采样器健康度与回退

| 指标 | B | C1 | C2 | C3 |
|---|---:|---:|---:|---:|
| 回退到官方随机采样的比例 | — | 0.000 | 0.000 | 0.000 |
| 候选有效率 | — | 1.000 | 1.000 | 1.000 |
| 平均选中先验分数 | — | 见 JSON | 见 JSON | 见 JSON |

在 60 张真实图像上，**没有任何一张触发回退**，候选有效率 100%。原因：候选块尺寸都满足 `min_keep`，且先验图的动态范围都非退化。回退路径只在合成测试（空白图、纯土、极低对比度）中被触发，见 `tests/test_stage4a_masks.py`。

### 3.4 计算开销

| 方法 | 单张先验生成时间 |
|---|---:|
| B（无先验） | 0.56 ms |
| C1 | 4.06 ms |
| C2 | 3.27 ms |
| C3 | 3.25 ms |

在正式训练中，`num_workers=0` 时该开销计入主进程：每 batch（16 图）约 16–56 ms，相对 260–280 ms 的前向/反向是约 **6%–20%** 的额外 CPU 开销，且实测被 GPU 计算掩盖（见 `stage4a_training_benchmark.md`）。

## 4. 已知局限（观测到的失效案例）

- **黄化/枯死植被**：样本 `vgn_VegAnn_1101`（index 40）中，视觉检查显示 C1 的目标块落在**枯黄茎秆**区域，但 ExG 数值仍高于替代位置（0.550 vs B 的 0.478）。说明 ExG 的"植被"与人类视觉的"活体绿色植被"不完全一致——这正是文档中声明的失效模式，而非实现错误。
- **边界被土壤纹理淹没**：C2 的收益（+1.6 pp）小于 C1（+7.3 pp），与"裸土、石块、残茬也产生强梯度"的预期一致。
- **C1 与 C3 在 2/60 张图上选中了同一位置**：这是候选采样（K=16）下两个不同先验偶然选中同一块的巧合，不是 C3 未打乱。已单独验证两图的 C3 先验图与 C2 不同（`shuffle actually changes the map: True`）。

## 5. 对本轮实验的意义

- Gate 2 的三项要求全部满足：引导区域分布**确实改变**、几何满足公平性、异常输入有安全回退。
- 由于 C3 对照明确无效，若最终 C2 > B 而 C3 ≈ B，则可以较有把握地把差异归因于**空间对齐的结构信息**，而不是"有偏采样"这一混杂因素。
- 反之，若 C2 ≈ C3，则说明收益（即使存在）不来自结构语义，需要在结论中如实降级解释。
