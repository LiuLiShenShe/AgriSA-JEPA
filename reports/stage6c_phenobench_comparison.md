## 结果解读（基于上述实测值；解释性，不是新测量）

- **B1-A**：mIoU +1.17 pp；crop +0.76，weed +2.69，soil +0.08；mIoU 方向 3 正 / 0 负。
- **B2-A**：mIoU +0.96 pp；crop +0.77，weed +2.03，soil +0.08；mIoU 方向 3 正 / 0 负。
- **B2-B1**：mIoU -0.21 pp；crop +0.01，weed -0.66，soil +0.00；mIoU 方向 0 正 / 3 负。

1. B1−A 与 B2−A 的 mIoU 差值为 +1.17 / +0.96 pp；crop 为 +0.76 / +0.77 pp，weed 为 +2.69 / +2.03 pp。
2. B2−B1 的 mIoU 差值为 -0.21 pp（0 正 / 3 负）；weed 为 -0.66 pp，crop 为 +0.01 pp。
3. 收益由 crop/weed 而非 soil 驱动：B1−A 与 B2−A 的 soil 差值幅度均小于 crop 与 weed。
4. 三臂 loss、probe 耗时与显存见“训练可比性”表；三臂优化路径可比，loss 量级由 soil 像素占比主导，不能单独作为效果优劣证据。
5. 官方评价器与自实现指标最大偏差 0.005000 pp（< 0.01 pp）；val 完整评价 772 张。
6. 在当前冻结 linear-probe + 2,000-update 设置下：B1/B2 相对 A 在 3/3 probe seeds 上呈初步正迁移信号；但每个 arm 只有一个预训练 checkpoint，3 个 probe seeds 不估计预训练方差。B2−B1 的 |mIoU 差值| 小于两 arm 的 probe-seed std，且类间方向不一致，不能判定采样策略优劣。下一步应优先用独立预训练 seeds 复现 B>A，再决定是否进入 GWHD 检测或更长训练。

## 解释边界

- probe seeds 0/1/2 只衡量分割头/训练随机性；每个 arm 只有一个预训练 checkpoint。
- 不报告 p 值，不宣称预训练方法显著优越；B2−B1 为探索性方向。
- 差值小或逐类方向不一致时保留 mixed/不确定结论。
- 未使用 test split，未在 test 上调参。
