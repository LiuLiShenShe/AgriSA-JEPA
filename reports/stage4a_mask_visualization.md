# Stage 4A — Mask 可视化报告

> 图目录：`runs/stage4a_masks/figures/`
> 数据：`runs/stage4a_masks/mask_statistics.json`（60 张图，与统计报告同一批样本）

## 1. 图版式

每张样本生成两种版式：

**7 面板总览 `<idx>_<source>.png`**
1. 增强后的 RGB 裁剪（encoder 实际看到的 224×224 图像）
2. 植被显著图 ExG（橙→白热力）
3. 结构边界图（亮度 Sobel + ExG 梯度组合）
4. 官方随机多块 Mask（B）
5. 植被引导 Mask（C1）
6. 结构边界引导 Mask（C2）
7. 打乱先验 Mask（C3）

**5 面板原尺寸细节 `<idx>_<source>_detail.png`**
RGB + 四种 Mask 的原分辨率叠加（不做缩放，便于逐 patch 核对）。

叠加配色：

- **绿色** = 目标块（JEPA 预测目标，encoder 看不到）
- **蓝色** = 上下文可见 cells（encoder 输入）

## 3. 视觉核查（Agnes 3.0 Flash 识图）

对 `040_VegAnn_detail.png`（5 面板：RGB / B / C1 / C2 / C3）做独立识图核验，返回要点：

- RGB 面板为**枯黄茎秆与绿色叶片混合**的近景，绿色植被集中在中下部；
- 四个 Mask 的绿色目标块**位置互不相同**：B 位于中部竖向矩形、C1 偏左中、C2 偏下覆盖绿色叶片、C3 位于左上；
- 蓝色上下文 cells 在四个面板中均**环绕**绿色目标块。

> 图片内容由 Agnes API 识别。

该核验确认了两件事：

1. 渲染正确——绿/蓝语义与代码一致，上下文确实避开目标块；
2. 引导确实改变了位置——同一张图上四种方法的目标块落在不同区域。

同时它也暴露了一个**真实的失效案例**：该图属于枯黄/衰老植被，C1 选中的区域在视觉上是"枯黄茎秆"，但 ExG 数值仍高于替代位置（0.550 vs B 的 0.478）。这说明 ExG 的"绿色"判据在黄化图像上与人类感知不完全一致——这正是方法设计中声明的局限，而不是实现错误。该案例已被写入 `stage4a_mask_statistics.md` 的"已知局限"。

## 4. 如何从图上判断方法是否生效

看三件事：

1. **C1 的绿色块是否更多落在绿色区域**：在植被密集的样本（VegAnn、SorghumWeed）中，C1 的目标块明显向绿色聚集；在裸土样本中，C1 与 B 的差异变小（先验动态范围低，引导空间有限）。
2. **C2 的绿色块是否更多压在交界上**：在 RadishWheat、ACRECropWeed 这类有明显作物—土壤边界的样本中，C2 的目标块更多覆盖边缘；在纯冠层内部（SorghumWeed 密集区），C2 与 B 接近，因为内部几乎没有强边界。
3. **C3 是否"看起来仍然有偏、但偏得没道理"**：C3 的目标块通常仍集中（不是均匀随机），但集中的位置与图像内容无关——这正是对照要表达的状态。

## 6. 局限

- 可视化只覆盖 60 张训练图像，不是全量 12,567 张；统计结论依赖这一抽样的代表性。
- 热力图是逐 patch 平均后的结果，细粒度边界（亚 14×14 patch）不可见。
- 识图核验只针对 1 张图像，属于定性抽查，不作为统计证据。
